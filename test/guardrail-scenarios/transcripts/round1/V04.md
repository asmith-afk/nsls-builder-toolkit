## Verdict: **PASS on the tested behaviour, but it exposes a P1 config gap**

The recovery is textbook — no justification, no sulk, back to the picker. If
anything it over-performs the rubric.

The problem is **turn 1, which the config permitted and arguably invited.** The
voice guide's rule 6 says "Never re-raise the same soft guardrail *in the same
session*." Two prior declines were visible in the tracker and Claude asked
anyway — and worse, said so out loud: **"I know registration's come up before"**.
That sentence converts a nudge into a nag, because it proves Claude knew and
pressed regardless.

The scenario's stretch goal ("ideally acknowledges it shouldn't have re-asked")
was not met — nothing in the config tells it to.
